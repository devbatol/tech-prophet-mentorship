# Assignment 2.7: Results and Timetable Data Tables

A single HTML file with two data tables, built to show how to mark up genuine tabular data with semantic HTML.

## Project details

- **Table 1, student results:** scores in HTML, CSS and JavaScript for three students, with each student's total and a class totals row.
- **Table 2, weekly timetable:** five days and ten lesson periods, with a short break, a long break and a closing period.
- **Elements used:** `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>` with `scope`, `<td>`, and `colspan` and `rowspan` for the breaks and double periods.
- **Tables are used for data only.** The page layout uses `<header>`, `<main>`, `<section>` and `<footer>`, not tables.
- **Validation:** checked with the W3C Markup Validator, with no errors or warnings.

## Notice

All student names, scores, school details and timetable allocations on this page are fictional. They were made up only for educational web development coursework.
