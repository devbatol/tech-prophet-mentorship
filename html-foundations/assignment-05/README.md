# Assignment 2.5: Accessible Profile Images and Media

A personal profile page built with plain HTML. It has a meaningful profile image, a decorative image, a figure with a caption, a native audio player and a native video player, each with fallback text.

## Project structure

```
assignment-05/
├── index.html
├── README.md
└── media/
    ├── profile.jpg
    ├── divider.png
    ├── recipe-page.png
    ├── intro-audio.mp3
    └── recipe-page-navigation.webm
```

All media files are stored inside the project. Nothing is hotlinked from another website.
